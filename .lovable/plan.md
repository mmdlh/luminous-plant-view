# 智慧工厂平台实施计划

## 成品结构
- 建立 7 个一级页面：综合态势、生产调度、设备监控、能源管理、质量分析、仓储物流、安全环保。
- 使用固定毛玻璃顶栏：左侧大标题，右侧图标加文字的宽幅菜单；桌面端横向展示，窄屏可横向滑动。
- 七个页面采用明显不同的布局构图、信息密度和重点模块，不套用同一种卡片模板。

## 视觉呈现
- 以高亮青蓝、工业橙、信号绿为主，搭配鲜明的智慧工厂实景背景。
- 使用高透明毛玻璃卡片、流光渐变边框、悬浮抬升、发光数字和立体数据色彩。
- 动效保持科技感但不过度干扰阅读，并支持减少动态效果的系统设置。

## 数据与交互
- 每页配备与主题匹配的统计指标、状态灯、丰富表格及折线图、柱状图、雷达图、饼图等混排图表。
- 图表随窗口变化自适应；折线和混合图图例置顶，并预留顶部空间避免遮挡。
- 提供可用的菜单切换、时间/状态筛选与关键设备状态反馈。

## 技术细节
- 基于现有 React 页面实现，安装并使用 ECharts 渲染图表。
- 统一视觉变量写入全局样式，页面仅使用语义化颜色和样式。
- 为首页补全独立标题、简介、Open Graph 与 Twitter 元数据。
- 完成后检查桌面与手机布局、交互、图表渲染和当前构建状态。
